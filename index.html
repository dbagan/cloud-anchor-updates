Cloud Anchor

A macOS app and command-line tool for managing cloud credentials.

Install

brew install --cask dbagan/tap/cloudanchor

Updates

Today, update with brew upgrade --cask cloudanchor. In-app updates are coming: a future version will update itself from this update feed (Cloud Anchor ▸ Check for Updates…). Each update will be notarized by Apple and signed with Cloud Anchor’s update key.

Downloads for every version are on the releases page.
